# Habit Tracker
Live demo: https://your-app-name.onrender.com

A personal habit tracker built with Flask and SQLite.

## Features

- Track habits over the last 7 days
- Streak counter for each habit
- Add and delete habits

## Setup

    git clone https://github.com/daintysteph/habit-tracker.git
    cd habit-tracker
    python3 -m venv .venv
    source .venv/bin/activate
    pip install flask
    python3 app.py

Then open http://127.0.0.1:5000 in your browser.

## Built with

Python, Flask, SQLite, HTML, CSS
